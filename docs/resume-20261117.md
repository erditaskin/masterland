# Sabah devam notu — 17 Kasım 2026

Kullanıcı son olarak incelemenin tamamlanmasını, telefonun artık kullanılmamasını ve sabah devam edilmesini istedi. Geliştirme ve dağıtım bu noktada durdurulmuştur.

## Google girişinde kesin gözlem

Kullanıcı hem erdi@soruders.com hem erditaskin@gmail.com ile giriş sonrası yeniden giriş ekranına döndüğünü bildirdi. Supabase Unified Logs, son 60 dakika Auth filtresinde dört POST /token isteği için HTTP 400 ve şu mesajı gösterdi:

`Invalid request: Passed nonce and nonce in id token should either both exist or not.`

Bu gözlem e-posta veya test listesi varsayımıyla açıklanmamalıdır. Native Google SDK'nın ID token nonce sözleşmesi ile Supabase'e verilen nonce birlikte incelenecektir. Nonce kontrolleri kapatılmamıştır ve doğrudan kapatılmamalıdır. Kurulu @react-native-google-signin/google-signin paketinin src/ios dizinlerinde nonce seçeneği araması sonuç vermedi; desteklenen API ve token sözleşmesi resmî dokümanla doğrulanmadan çözüm seçilmedi. Tokenlar/kimlik bilgileri dışarı aktarılmadı veya loglanmadı. Apple akışı değiştirilmemelidir.

## Google nonce düzeltmesi — 17 Kasım devam turu

Google için yerel SDK ID token yolu kaldırıldı. Ücretsiz SDK, token içindeki nonce için Supabase'e verilecek ham nonce değerini sunmuyordu. Google, Facebook ile ortak sistem tarayıcısı OAuth + PKCE akışını kullanır. Supabase nonce kontrolü kapatılmadı. Google hesap seçimi açıkça istenir; dönüş adresi doğrulanır, kod oturuma çevrilir ve getUser başarılı olmadan giriş tamamlanmış sayılmaz. Apple native nonce akışı korunur.

TypeScript, ESLint ve 115 birim/regresyon testi geçti. Google/Facebook için token yolunun kullanılmadığı, kod değişimi, iptal, sunucu doğrulama hatası ve yanlış callback kontrolleri test edildi. Gerçek Google hesabıyla cihaz kabulü ayrıca gereklidir; birim testi gerçek sağlayıcı kabulü anlamına gelmez.
